# react-native-hinges 0.1.0-alpha.1

Draft candidate notes. This version has not been published. The npm
`0.1.0-alpha.0` package reserves the name and contains no functional hinge API.

## New

- Initial native hinge observations for React Native's New Architecture.
- `useHinges()` returns a read-only array of native posture
  and angle snapshots. Angles use radians; unavailable readings remain `null`.
- `createHingeObserver(rootTag)` exposes `get()` and `subscribe()` for non-React code,
  scoped to an existing React root. No provider or view ref is required.
- Optional `react-native-hinges/reanimated` exports
  `useAnimatedHinges()`. Native events supply a Reanimated shared value while
  preserving ordinary React and observer consumers.
- UIKit `UIHingeInteraction` on iOS 27.1 and later. Typed API calls use an SDK
  compile guard and a runtime availability check. Older-SDK builds compile out
  observation even when later installed on a newer device.
- Android WindowManager posture for multiple folding features. A hinge-angle
  sensor supplies radians only when it can be associated unambiguously with a
  single hinge. The package does not infer posture from angle thresholds.
- React Native 0.88 RC example and Docusaurus documentation source. The default
  Field Notes journal combines reserved-region page layout with hinge-driven
  perspective and lighting. Sensor Lab exposes readings and diagnostic controls.
  The example pins the separate reserved-regions implementation to a GitHub
  commit; it is not a dependency of the published hinges library.

## Requirements and limits

- Fabric / New Architecture is required. The example uses RN `0.88.0-rc.1`;
  broader React Native compatibility has not been established.
- iOS observations require both an iOS 27.1-or-newer SDK and runtime.
- Android requires API 24 or later; angle sensors require API 30 or later and
  supported hardware or an emulator implementation.
- Reanimated `^4.7.0` and Worklets `^0.13.0` are optional peers, needed only for
  the animated entry point. The example uses `4.7.0` and `0.13.0`.
- Native array positions are not stable hinge identities. Multiple Android
  features retain their postures but have `null` angles when sensor association
  is ambiguous.
- No fixed event frequency, lossless hardware sampling, smoothing, or frame-rate
  guarantee is provided. Any demo smoothing is a presentation choice.
- The native cache clears when the root has no subscribers. An externally retained
  animated shared value currently keeps its last snapshot after native event
  observation is removed.
- Reserved-region geometry is provided by the separate
  [react-native-reserved-regions](https://github.com/appandflow/react-native-reserved-regions)
  package.

## Migration

There is no earlier functional npm API to migrate. After this candidate is
published, install its explicit version, install iOS pods, and rebuild the native
app. Animated consumers additionally install and configure the optional peers.
Do not treat the `0.1.0-alpha.0` placeholder as an implementation of these APIs.

## Verification

The baseline implementation at `1b3220b` passed the
[initial main CI run](https://github.com/appandflow/react-native-hinges/actions/runs/35536023446):
formatting, lint, type checks, tests, Bob build, docs build, packing, Android debug
build, and a generic iOS simulator build. The iOS log identifies Xcode 26.6 with
the iPhoneSimulator 26.5 SDK, which verifies the older-SDK compile path for that
baseline. It does not exercise iOS 27.1 hinge callbacks.

This evidence predates the optional animated integration. Before tagging this
candidate, record the exact reviewed commit and its CI run, packaged-subpath
checks, native runtime evidence, and any unavailable checks here.

The initial animated working-tree validation on Android 16 / API 36 used a
foldable emulator with native hinge-angle injection. It observed approximately
20 and 60 changed-angle events per second for corresponding host input sequences.
During the one-second JS-stall control run, the UI measurement recorded 642
changes over 10.728 seconds with a 32.379 ms maximum gap. Two fixed-angle cold
relaunches delivered the initial reading without further sensor movement.
These are emulator observations, not physical sensor or rendering-rate guarantees.
See the [method, raw counts, and limitations](../verification/android-emulator-2026-09-20.md).

A separate 22-second Android emulator recording exercises the combined Field
Notes screen through native callbacks from both libraries: three seconds flat
at 180°, sixteen seconds half-open with 180° → 60° → 180° angle sweeps, then three
seconds flat. An AOSP `display_features` override supplies the folding feature;
the emulator console supplies angle input. The clip shows the native-fold
caption, page-gap changes, perspective, and lighting. It does not show numeric
angle readings, an occlusion overlay, or the Sensor Lab JS-stall test. This is
emulator demonstration evidence, not physical-device performance validation.

The combined app also built with Xcode 27.1 beta and launched on the iPhone Duo
27.1 simulator. Native inspection returned `[{ angle: 0, status: 'closed' }]`
for hinges and `[]` for reserved regions inside the inset journal. The separate
iOS preview recording labels its generated angle as simulated; it is not
changing-angle native evidence.

The [Android demo recording](https://github.com/user-attachments/assets/4f7783d8-2d17-4615-b24a-b618be93436b)
retains normal timing and labels the Android emulator.

## Root-scoped implementation

The provider-free implementation has separate [Android runtime evidence](../verification/root-observer-2026-09-20.md)
and [iOS runtime evidence](../verification/root-observer-ios-2026-09-20.md).
The hook and explicit observer seed a JS-owned immutable snapshot from the native
cache and refresh through subscriptions. The animated hook receives native events
on the UI runtime after its registration handshake. First uncached renders can
still return `[]`; no API blocks React waiting for OS initialization.

Android validation includes fixed-angle startup, matching animated/React/observer
readings, navigation cleanup, and about 60 updates/s during a one-second JS stall.
These are emulator results, not physical-device guarantees. The root-tag event
adapter uses RN 0.88/Reanimated 4.7 internals and requires compatibility checks
when those dependencies change.

On the iOS 27.1 Duo simulator, static native closed/zero-angle readings reached
the React hook, explicit observer, and animated hook on cold start and remount.
Changing native iOS angles remain unverified.
